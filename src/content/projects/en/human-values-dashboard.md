Interactive dashboard built with Python and Dash, exploring Schwartz human value orientations across 14 European countries using data from the European Social Survey (Rounds 1-11, 2002-2023). The dashboard includes four views: a single-country radar chart with higher-order dimension arcs, a PCA-based Value Space that places countries by profile similarity with K-Means clustering, a parallel coordinates view showing IQR bands per Schwartz dimension across 11 attitude axes, and a country-level macro indicator view. Macro data is integrated from V-Dem, OECD, and Eurostat.
